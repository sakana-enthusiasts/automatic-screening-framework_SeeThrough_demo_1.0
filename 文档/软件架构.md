# 软件架构

```text
启动程序.py
  └─ 软件界面/主界面.py
       └─ 核心系统/流程控制器.py
            ├─ 核心系统/插件管理器.py
            ├─ 核心系统/运行数据管理.py
            ├─ 设置/（字段、规则、插件和毒性配置）
            └─ 插件/
                 ├─ 数据导入
                 ├─ 化学计算
                 ├─ 数据合并
                 ├─ 筛选与评价
                 ├─ 结果展示
                 ├─ 透明化预测
                 └─ 实验优化
```

## 数据边界

`核心系统/数据管理接口.py` 定义共享数据访问边界，`运行数据管理.py` 以运行编号隔离用户导入、临时文件、筛选记录、模型结果和导出文件。论文原始数据被当作只读输入；运行中生成的数据保留在本地并由 `.gitignore` 排除。

## 模块状态

- **已实现**：数据导入、字段标准化、候选身份与结构处理、RDKit 描述符、Hansen 距离、配置化规则筛选、报告和图表导出。
- **部分实现**：毒性证据的本地数据结构、GHS 提示、可选查询接口和界面展示；不执行按实验室标准的自动毒性淘汰。
- **接口预留，当前演示未启用**：高斯过程预测、BoTorch 实验优化。接口文件保留用于未来接入经过验证的训练/实验数据，不代表模型已经训练、验证或可用于决策。
